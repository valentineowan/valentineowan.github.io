Diploma mini project · 2013

The Role of Operating System to the Computer System/System Communication

This mini project explored the role of an operating system in coordinating a computer’s hardware and software, providing an environment for programmes to run, and supporting communication between the user, applications and computer components.

Diploma in Computer Repairs and Maintenance (DCRM) · Pacific Computers and Management College, Calabar · December 2013

Read project (PDF) SSRN record Back to all projects

Plain-language summary

A computer relies on an operating system to coordinate its basic operations. The operating system acts as an intermediary between the computer’s hardware, application software and user. Without it, users would have difficulty running programmes and making effective use of components such as the processor, memory, storage devices and input/output equipment.

This 2013 mini project introduced the role of operating systems and reviewed explanations of how they manage hardware resources and provide an environment for application software. Its discussion covered the coordination of components, the management of memory and storage, the handling of input and output, and the relationship between operating systems and programmes installed on a computer. The project used a review-based approach, drawing on literature and explanatory sources rather than reporting a survey or experiment.

The central message is that the operating system is fundamental to the practical operation of a modern computer. It helps applications use available resources and enables hardware components and software to work together. This provides a basic conceptual foundation for understanding computer maintenance and troubleshooting.

Abstract

This mini project is a qualitative study examining the role of an operating system in computer system communication. It discusses how the operating system manages computer hardware and software, provides an environment for application programmes to run, and coordinates communication between the user, software and computer components. The review considers the operating system’s role in managing resources such as the processor, memory, storage and input/output devices, and explains why an operating system is essential to the effective functioning of a modern computer.
